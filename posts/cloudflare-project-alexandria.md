Cloudflare Project Alexandria provides recurring annual service credits to open-source projects. The program can cover Cloudflare plans and increased use of Workers and Pages, R2 storage, and enhanced Zero Trust access. It offsets infrastructure costs rather than providing cash.<!--more-->

**Eligibility and application.** The current program page says applicants must maintain an open-source project with a recognized license, operate solely on a nonprofit basis, and align with the program's mission. Submit a sponsorship request using the **Contact us today** button on the [Project Alexandria page](https://www.cloudflare.com/lp/project-alexandria/). The page does not describe application fields or a review timeline. Acceptance and the benefits awarded are at Cloudflare's discretion.

**Availability and terms.** The program page currently invites sponsorship requests but publishes no application deadline, credit amount, or recipient count. Credits cannot be transferred, refunded, or exchanged for cash. Cloudflare requires an account with a valid payment method on file; product-specific limits and taxes may apply. Service use is also governed by [Cloudflare's terms](https://www.cloudflare.com/terms/).

**Eligibility wording caveat.** Cloudflare's 2024 [program announcement](https://blog.cloudflare.com/expanding-our-support-for-oss-projects-with-project-alexandria/) describes projects operating solely on a nonprofit basis **and/or** otherwise aligning with the program mission. The current program page says nonprofit operation **and** mission alignment. Projects that rely on the broader wording should confirm eligibility with Cloudflare.
