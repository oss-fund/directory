Codex for Open Source is OpenAI's maintainer-support program for active, important public repositories. Selected maintainers may receive one or more benefits: six months of ChatGPT Pro with Codex, API credits for core project work, or conditional Codex Security access. API credits and security access are optional additional benefits subject to review; this is operational support, not a cash grant.<!--more-->

**Eligibility and application.** OpenAI invites core maintainers and maintainers of widely used public projects to apply, and says projects that do not fit those descriptions may still apply if they are important to the ecosystem. The developer page says applicants may apply for their own project or nominate another maintainer. The current form asks for the applicant's ChatGPT-account email, public GitHub profile and repository, maintainer role, evidence of project importance, OpenAI organization ID, and intended API-credit use. Applications are reviewed on a rolling basis; selected applicants are notified by email. Submission does not guarantee selection.

**Benefits and terms.** The program page lists six months of ChatGPT Pro with Codex, but the program terms say benefit duration, scope, and timing may vary. OpenAI may award one or more benefits at its discretion. Benefits are limited, personal, non-transferable, and have no cash value. API credits and Codex Security can require separate review and terms; OpenAI may change or discontinue benefits. Recipients are responsible for applicable taxes, and applicants should not submit confidential information.

**How the fund relates.** The current program page describes the Codex Open Source Fund as the source of API credits within this broader maintainer program. OpenAI's separate older fund-form page describes a $1 million initiative and grants of up to $25,000 in API credits. The current program form does not publish a per-project credit amount, so that older $25,000 figure is not presented here as a current individual award. There is no separate Codex Open Source Fund listing in this directory.

Apply through the [current Codex for Open Source form](https://openai.com/form/codex-for-oss/) and review the [program terms](https://learn.chatgpt.com/docs/codex-for-oss-terms). The [older Codex Open Source Fund form](https://openai.com/form/codex-open-source-fund/) remains accessible but describes the earlier API-credit initiative.
