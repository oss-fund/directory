Dosu is an AI documentation and knowledge agent for software teams that connects to GitHub and turns code, issues, pull requests, and discussions into searchable project knowledge. For open source projects, it offers a free maintainers' workflow and public knowledge spaces that can reduce documentation churn and repetitive support work.<!--more-->
