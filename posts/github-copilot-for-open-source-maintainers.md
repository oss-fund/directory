GitHub gives maintainers of popular open source repositories a route to free individual access to GitHub Copilot Pro. This is product access that can reduce tooling costs, not cash funding.<!--more-->

**Eligibility and access.** GitHub does not publish a numeric popularity threshold. To check, open Copilot settings from your GitHub profile. If GitHub determines that you qualify, the page offers access to Copilot Pro; you then configure Copilot use policies and complete setup. GitHub reevaluates eligibility monthly. There is no separate maintainer application form or approval guarantee documented.

**Availability and terms.** GitHub Community Admin said signups for Copilot plans would reopen gradually starting June 16, 2026, over the following couple of weeks. GitHub's current [plans page](https://github.com/features/copilot/plans) lists Copilot Pro with a “Get started” option. Eligible maintainers can check their account's Copilot settings for the complimentary route; GitHub determines eligibility and reevaluates it monthly, so access is not guaranteed. GitHub says a plan granted through maintainer eligibility cannot be canceled. Its [Terms of Service](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service) also apply to Copilot: for individual licenses, inputs and outputs may be used to develop and improve models unless you opt out in account settings, and generated output should be reviewed and validated.

See GitHub's [maintainer access instructions](https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-teachers-and-os-maintainers), [Copilot plans](https://github.com/features/copilot/plans), and [June 2026 signup reopening update](https://github.com/orgs/community/discussions/197089) for current details.
