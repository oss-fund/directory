GitHub Sponsors lets people and organizations fund open source contributors through GitHub profiles. Sponsored developers and organizations can offer one-time and monthly tiers, with optional benefits set by the recipient. This is community-funded support, not a grant or guaranteed income.<!--more-->

**Eligibility and application.** Individual contributors who provide value to an open source project and live in a supported region may apply; if using bank payouts, their residence and bank-account regions must match. Organizations must contribute to an open source project and legally operate in a supported region. An organization first joins the waitlist and can complete setup after GitHub invites it; for bank payouts, the person setting it up must also live in a supported region. Sponsors can participate from any region, while maintainers in unsupported regions can join the waitlist. Setup includes a Sponsors profile, bank-account or fiscal-host payout choice, required tax and payout information, two-factor authentication, acceptance of GitHub's additional terms, and an approval request in the Sponsors dashboard. GitHub says review may take a few days; acceptance is not automatic.

**Fees and caveats.** GitHub charges no fee on sponsorships from personal accounts. Sponsorships from organization accounts can incur up to 6%: 3% card processing and 3% GitHub service fee; invoiced billing removes the card-processing fee. Where Stripe Connect is used, Stripe's terms govern recipient payouts; taxes and other payment-route costs may apply. GitHub's Sponsors Matching Fund is closed to new applications and is not a current benefit.

See GitHub's [program overview](https://docs.github.com/en/sponsors/getting-started-with-github-sponsors/about-github-sponsors), [personal-account setup](https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-personal-account), [organization setup](https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-organization), [fees and taxes](https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes), and [Additional Terms](https://docs.github.com/en/site-policy/github-terms/github-sponsors-additional-terms).
