Hopsie is built for nonprofits that need fundraising pages, recurring donations, peer-to-peer campaigns, donor messaging, and integrations without piecing together multiple separate systems. It is not OSS-specific, but it is still a useful reference point for donor-oriented fundraising software that combines campaigns with CRM-style follow-up.<!--more-->
