JetBrains offers free developer-tool subscriptions to established open-source projects whose active work has a broad impact on the developer ecosystem. This reduces tooling costs; it is not cash funding.<!--more-->

**Eligibility and application.** Project leads and core contributors can apply. The request form asks for the project website, repository, license, number of requested licenses, project details, and evidence of the applicant's contribution. JetBrains says licenses are for active contributors whose contributions are regular and visible in the repository; non-code commits do not count as active development. Each application is reviewed individually, so applying does not guarantee approval. JetBrains also offers a separate no-application non-commercial IDE option for individual contributors and small early-stage projects.

**Benefits and terms.** The project program offers complimentary All Products Pack subscriptions; the request form also allows applicants to ask for full Team Tools licenses. Subscriptions are assigned per user and last one year. Use is restricted to non-commercial open-source development for projects meeting the Open Source Definition. Renewals require a new application and JetBrains' approval. Review the current [Open Source Projects subscription agreement](https://www.jetbrains.com/legal/docs/toolbox/license_opensource/) before applying.

Apply through JetBrains' [Open Source Development License form](https://www.jetbrains.com/shop/eform/opensource), and check the [program overview](https://www.jetbrains.com/community/opensource/) and [licensing FAQ](https://sales.jetbrains.com/hc/en-gb/articles/207240575-Does-JetBrains-offer-licenses-for-user-groups-tech-communities-or-open-source-project) for current details.
