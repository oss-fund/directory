The Open Source Security Foundation is a Linux Foundation initiative that coordinates projects, guidance, events, and funding to improve the security of the open source ecosystem. It matters to OSS.Fund because it is both a strategic funder and a major operational backbone for security-focused sustainability work in OSS.<!--more-->
